LFA Image Analysis GUI

A browser-based static HTML version of the lateral flow assay image analysis interface. It loads assay images from GitHub, lets users select regions of interest, applies basic grayscale/inversion processing, extracts intensity profiles, estimates signal-to-baseline ratios, and exports saved ROI data.

How this static version works

The original notebook used Python, Flask, OpenCV, pandas, and Matplotlib routes to load images, crop ROIs, export arrays, build DataFrames, and plot SBR/final graphs. GitHub Pages cannot run that Python backend. This export recreates the user-facing workflow in browser JavaScript so the interface can run as a static website.

Image discovery uses the GitHub Trees API, then loads images from raw.githubusercontent.com. PNG/JPG files load natively; TIF/TIFF files are decoded in the browser with UTIF.js. ROI analysis is performed on canvas pixel data.

GitHub source: timrobinson/UW-LFA-Analysis/100microliters/Database. If GitHub API rate limits occur, refresh later or generate an image manifest.
